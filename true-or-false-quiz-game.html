About this app

True or False Quiz Game — a two-player quiz for one big screen and two iPads. The Host screen shows the question, timer, scores and the winner; each player gets their own screen with just two big TRUE / FALSE buttons.

How a live game runs: in Live, press “Create Live Room for iPads”, then give the players the room code (it only ever appears here in Admin). Players open their Player link, enter the code and their name, and their taps count live on the Host screen. Start, reveal, end and reset are all controlled from Live. The Live monitor at the top of Live shows each player's screen link, Connected / Disconnected status, score, correct count, streak, current answer, answer time, recent answers, plus the current question and the timer.

Designing: in Screens you edit a draft of each screen — the canvas previews every change as you make it, but the Host and Player screens keep showing the last published design until you tap Go Live at the bottom of Admin. Go Live means one thing only: it publishes the design live to all screens at once.

Screens: Host (main address) · Player 1 (/Player1) · Player 2 (/Player2) · Admin (/Admin). No accounts or installs — everything runs in the browser.

🚀 Go Live — publish to screens Edits are drafts until you Go Live. Tapping Go Live sends them straight to the Host & Player screens instantly — no file, no download.
Each screen lives at its own link — Host at the main address, /Player1 and /Player2 for the players, /Admin to design all three screens and run the quiz. Live play: host creates a room → iPads join with the code → taps count live on the host.
